PROJECT OBJECTIVE
-----------------
The goal of the project was to test whether a continuous latent-action representation can be a useful alternative to LAPA-style codebook/VQ latent actions.

Main comparison:
  1. VQ/codebook baseline latent Z
  2. Continuous Z with anti-collapse regularization
  3. Naive continuous Z without anti-collapse regularization

The work focused only on Phase 1:

  (x_t, x_{t+1}) -> z_t -> reconstruct x_{t+1}

No Phase 2 VLM pretraining and no robot policy/action fine-tuning were run.

THREE-WAY COMPARISON
--------------------
A third model, naive continuous Z, was trained without anti-collapse loss.

Three-way STHV2-100 result:

  VQ Z: (1625, 32)
  Naive continuous Z: (1625, 32)
  Anti-collapse continuous Z: (1625, 32)

  Method                         mean_abs   std_mean   std_min   std_max   effective_rank
  VQ/codebook                    0.045011   0.047229   0.019612  0.065400  9.026680
  Naive continuous               0.076556   0.048197   0.026523  0.073535  20.622343
  Continuous + anti-collapse     0.806973   0.883825   0.809668  0.954372  21.612843

Interpretation:
  - Naive continuous did not collapse to low rank; rank was 20.62.
  - However, the naive latent was very small-amplitude and poorly scaled.
  - Anti-collapse continuous Z had similarly high rank but much larger, well-spread latent variation.
  - This supports the story that simply removing the codebook is not enough; the latent space needs structure.

Presentation framing:
  - Naive continuous: good reconstruction but weak/uncontrolled latent scale.
  - VQ/codebook: imposes discrete structure, avoids fully unconstrained continuous latents, but can be coarse.
  - Continuous + anti-collapse: keeps fine-grained continuous motion while forcing a well-conditioned latent space.

FAILURE CASE ANALYSIS
---------------------
A pairwise evaluation script ranked videos where VQ/codebook was worse than continuous. The failure score combined:

  1. VQ reconstruction error minus continuous reconstruction error
  2. VQ code dominance within a video
  3. Continuous effective-rank advantage over VQ

Top failure panels were generated for selected trajectories.

Intuitive explanation of top cases:

Rank 1: Moving dog figurine and elephant away from each other
  - VQ used only 1 code.
  - top code fraction = 1.00.
  - VQ rank about 1.22; continuous rank about 4.78.
  - The motion is subtle, involving small object displacement against a mostly static background.
  - VQ compresses the entire sequence as the same action, while continuous Z captures gradual displacement.

Rank 2: Lifting purse with ring on it
  - VQ used more codes but still reconstructed poorly.
  - This involves hand-object interaction, occlusion, and deformation.
  - Continuous Z captures more graded transition structure.

Rank 3: Dropping a battery next to an image
  - Small object motion against a largely static frame.
  - VQ can miss the tiny object displacement because most pixels are unchanged.
  - Continuous Z better preserves small-motion variation.

Rank 4: Pulling two ends of a paper ribbon so it separates
  - Gradual physical transformation, not naturally represented by one token.
  - VQ mostly uses a dominant code with abrupt switches.
  - Continuous Z traces a smoother trajectory.

Rank 5: Pulling two ends of a comb but nothing happens
  - The final object state changes little, but the attempted action has hand motion and tension.
  - VQ collapses the attempt to one code.
  - Continuous Z captures attempted action dynamics even without a big final-state change.

Overall failure-case intuition:
  - VQ struggles when motion is small, continuous, deformable, occluded, or has little final-state change.
  - Continuous Z helps because it is not forced to quantize all transitions into a few discrete tokens.
