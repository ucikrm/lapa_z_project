PROJECT OBJECTIVE
-----------------
The goal of the project was to test whether a continuous latent-action representation can be a useful alternative to LAPA-style codebook/VQ latent actions.
Main comparison:
  1. VQ/codebook baseline latent Z
  2. Continuous Z with anti-collapse regularization
  3. Naive continuous Z without anti-collapse regularization

Work focused only on Phase 1: (x_t, x_{t+1}) -> z_t -> reconstruct x_{t+1}.
No Phase 2 VLM pretraining and no robot policy/action fine-tuning were run.

PART 2: CODEBASE CRITIQUE & SYSTEM FLAWS IDENTIFIED
--------------------------------------------------------------------------------

During detailed review of the local codebase, several critical flaws were identified:

1. ARCHITECTURAL FLAW: UNTRAINED APPEARANCE ENCODER
   - Inside `SmallDecoder` (phase1_models.py), the forward pass detaches the start frame $x_1$ representation:
     `x1_feat = self.x1_encoder(x1).detach()`
   - Because `x1_feat` is detached and there is no separate training step for `self.x1_encoder`, this encoder remains completely random/untrained throughout training.
   - Impact: The decoder is forced to reconstruct the next frame using random features from the start frame, making $Z$ overcompensate by encoding static appearance features rather than pure action dynamics.

2. CONFOUNDING VARIABLES: LAYERNORM AS HIDDEN ANTI-COLLAPSE
   - `LayerNorm` was only applied to the output of `ContinuousPhase1Model` and not to the naive models.
   - Per-sample normalization stabilizes latent scale and artificially inflates effective rank, making it a major confounding variable in the original comparisons.

3. MATHEMATICAL BOTTLENECK: BATCH SIZE VS. LATENT DIMENSION
   - Applying VICReg covariance loss on $d=32$ features with a batch size of $b=8$ creates a rank limit. The batch-centered latent matrix has maximum rank $b-1=7$.
   - Push to make covariance matrix diagonal (rank 32) conflicts mathematically with a rank-7 matrix, causing optimization instability. Batch size must be increased to $b \ge 64$.

4. CONCEPTUAL FLAW: NO-MOTION AMPLIFICATION
   - Applying LayerNorm independently per sample scales up zero-motion transitions (where the encoder should output 0) to have unit variance and equal magnitude to fast-motion transitions, destroying action scale information.

PART 3: FORMULATION OF THE FIVE COMPARED METHODS
--------------------------------------------------------------------------------

All methods map $(x_t, x_{t+1}) \rightarrow z \rightarrow \hat{x}_{t+1}$. The decoder is conditioned on $x_t$.

1. VQ/CODEBOOK
   - Map $z_e \rightarrow z_q$ (nearest codebook vector out of $K=64$).
   - Trained with straight-through estimator gradients, commitment loss, and codebook loss.
   - Behavior: Discretizes actions but causes low-rank geometry and code collapse.

2. NAIVE CONTINUOUS
   - Map to continuous $z$ directly with reconstruction loss only.
   - Behavior: Collapse-prone, arbitrary latent scale.

3. NAIVE + LAYERNORM
   - Map to continuous $z$ and apply per-sample LayerNorm before the decoder.
   - Behavior: High rank (26.34) but obliterates physical action magnitude.

4. OURS: VICREG CONTINUOUS, NO LAYERNORM
   - Map to continuous $z$ directly. Apply batch-wise VICReg variance/covariance regularizations.
   - Covariance loss pushes off-diagonals to 0 (decorrelation); variance loss pushes diagonals to 1 (prevents collapse).
   - Behavior: Achieves near-perfect rank (31.68 / 32) and preserves physical motion scale.

5. VICREG + LAYERNORM
   - Apply LayerNorm to $z$ per sample, then apply VICReg to the batch.
   - Behavior: Extremely stable but slightly lower rank (30.85) than Ours due to LayerNorm's row-sum constraints.
